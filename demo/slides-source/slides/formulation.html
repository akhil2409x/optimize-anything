Formulation

Variables

xₑₜ ∈ {0, 1}

1 if exam e is held in slot t

Hard constraints

Each exam in exactly one slot

No two conflicting exams in the same slot

Objective

Minimise the Carter proximity cost: each shared student costs 16 one slot apart, 1 five apart, 0 beyond

Binary variables and an NP-hard core (graph colouring) rule out gradient methods. The plan: greedy construction and local search at scale, ILP for small cases, bounds and repairs.

Metric order: feasibility, then proximity cost, then runtime. Every cost is recomputed by an evaluator that is independent of the solvers, which caught an ILP bug early on (failure log F1).
