claude.ai conversation still stored when the work finished. It covers:
- the end of Track D;
- all of Track J;
- the final deliverables: tool comparison, real Toronto data, the 4-core
  rerun, the report and the demo deck.

the session. Their prompts and AI responses are summarised in each track's
`prompts/<track>/001-*.md`. The complete conversation can be exported from
claude.ai (Settings → Privacy → Export data).

Claude Opus 5.5 in this session from the tracks' READMEs and generated
results.
